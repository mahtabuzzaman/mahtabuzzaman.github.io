How I work

Underneath every stage

From source system to decision

Most of my work follows this path: connect the systems a business runs on, refine the data in layers, and serve it to the reports and AI tools people use every day.

Select any stage to see what I do there.

Sources

I connect the systems a business already runs on, such as ERP and CRM platforms, SharePoint, on-premises databases and APIs, without disrupting them.

Tools: Dynamics 365 via Fabric Link, Microsoft Graph, REST APIs, on-premises gateways

Bronze

Data lands as it arrives, so nothing is lost and any load can be replayed or audited later.

Tools: Fabric Pipelines, Lakehouse, OneLake, incremental loads

Silver

I clean and standardize it, with consistent types, keys and business rules, and test it before anyone builds on it.

Tools: dbt, Spark notebooks (PySpark, Spark SQL), data quality checks

Gold

I model it into star schemas with shared dimensions, so each metric is defined once and every team gets the same answer.

Tools: dimensional modeling, Fabric Warehouse, T-SQL

Insight & AI

The model is served to Power BI apps and AI assistants: fast enough for daily use, governed enough to trust.

Tools: Direct Lake semantic models, Power BI, Fabric Data Agent, Copilot Studio

Release

Every change moves through Dev, Test and Prod with peer-reviewed pull requests and a way back if something breaks.

Tools: Azure DevOps pipelines, Git, Fabric deployment

Monitoring and cost

Alerts flag capacity, refresh and cost problems as they happen, and I tune workloads so the platform stays fast without overspending.

Tools: Logic Apps alerts, Fabric Capacity Metrics, FUAM, Python automation

Security and identity

Access stays tight and auditable across Microsoft 365 and Azure, from privileged roles to the service principals that run pipelines.

Tools: Entra ID (PIM, RBAC, Conditional Access), Intune, Defender

Selected work

Client details stay private. Here is what changed.

  • Silver, Gold, Insight & AI

    Rebuilt an enterprise reporting layer

    A global energy services company had more than a hundred overlapping SQL views behind its reports. I replaced them with a clean star schema, and the load on its Fabric capacity dropped from 90% to 30%.

  • Gold, Insight & AI

    One definition for every metric

    Reports sat on overlapping semantic models that didn't always agree. I merged them into one model per business area (14 became 8), so every app now reads the same KPIs.

  • Sources, Bronze

    Moved Dynamics 365 feeds to Fabric Link

    Migrated an integration from Synapse Link to Fabric Link, rewrote 140+ queries for Fabric and validated them row by row. The approach was later rolled out across the enterprise.

  • End to end

    Cloud spend in one view

    Built cost visibility products for six US clients in oil and gas, aerospace and engineering, bringing spend from several cloud providers into one Power BI view.
